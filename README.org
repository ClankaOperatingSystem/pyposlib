#+TITLE: pyposlib

Python library for a personal OS in Org files, beside the Emacs Lisp
[[https://github.com/monkeypants/poslib][poslib]]: two implementations, in lockstep, of the formats poslib's
=doc/formats.org= specifies. Org interpretation is poslib's alone.

- =archive_integrity.py= :: archive integrity ledgers: hash-chained,
  additive events per =archives/=, write bits removed from enrolled files,
  checkpoints of ledger heads.
- =cid.py= :: IPFS CIDs of files and trees, computed locally.
- =test/= :: unittest tests.

* Use

: python3 archive_integrity.py --help
: python3 archive_integrity.py check ROOT

Commands: =check=, =preview=, =apply=, =repair=, =verify-existing=,
=checkpoint=, =seal=, =write-new=. Exit 0 clean, 1 findings, 2 invalid
input or conflict.

* Check

- =make check=: the tests; poslib's shared fixtures, every one; and, with
  Emacs, poslib itself on random trees, which must give the same bytes.
  The fixtures come from =POSLIB=, a poslib checkout, else from =poslib/=,
  cloned and brought to =POSLIB_REF=, default =master=.
- =make check-ipfs IPFS=path/to/ipfs=: the CID fixtures against kubo,
  offline, with the unixfs-v1-2025 profile.
