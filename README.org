#+TITLE: pyposlib

Python library for a personal OS in Org files, beside the Emacs Lisp
[[https://github.com/ClankaOperatingSystem/poslib][poslib]]: two implementations, in lockstep, of the formats poslib's
=doc/formats.org= specifies and of the configuration its
=doc/pos-directory.txt= specifies. Org interpretation is poslib's alone.

The package is =pyposlib/=:

- =archive_integrity.py= :: archive integrity ledgers: hash-chained,
  additive events for each =archives/=, kept beside it in
  =archive-integrity/=; write bits removed from enrolled files;
  checkpoints of ledger heads; and the command line, poslib's.
- =cid.py= :: IPFS CIDs of files and trees, computed locally.
- =seal.py= :: sealing items into archives: a plan, reviewed, then applied.
- =remote.py= :: an archive kept away from its ledger, as poslib's
  =doc/remote-archive-protocol.txt= specifies: the client's port and its
  HTTP wire, and the keeping side, which verifies what it is sent and is
  what a server wraps around its storage.
- =tree.py= :: a node's configuration, in =.clanka/= or =.pos/=, as
  poslib's =doc/pos-directory.txt= specifies: read and checked, with its
  defaults filled in; the plan of what a tree needs, which changes
  nothing; and its application. Its command line is poslib's
  =pos-tree-batch=, command for command: =python -m pyposlib.tree plan
  ROOT=, or =pyposlib-tree= installed.

Beside it, =archive_integrity.py= at the top runs the command line from
a checkout, and =test/= holds the unittest tests.

* Use

The command line is poslib's =pos-seal-batch=, command for command.
From a checkout:

: python3 archive_integrity.py help
: python3 archive_integrity.py check ROOT
: python3 archive_integrity.py seal SOURCE DESTINATION > plan.json
: python3 archive_integrity.py apply plan.json "$(shasum -a 256 plan.json | cut -d' ' -f1)"

Installed, the same commands are =pyposlib ...= or =python -m pyposlib ...=,
and the library is =from pyposlib import archive_integrity, cid, seal=.
It needs Python 3.11 or later, and PyYAML for =tree.py=; the rest uses
nothing outside the standard library.
Install it from the repository at a tag:

: pip install "pyposlib @ git+https://github.com/ClankaOperatingSystem/pyposlib.git@v0.1.0"

Commands: =seal SOURCE DESTINATION [--apply]=, =write-new DESTINATION
[--apply]= (the record on standard input), =apply PLAN HASH=, =check ROOT=,
=checkpoint ROOT=, =repair ROOT=, =convert ROOT= and =help=. Exit 0 done or clean, 1
findings, 2 refused.

* Check

- =make check=: the tests; poslib's shared fixtures, every one; and, with
  Emacs, poslib itself on random trees, which must give the same bytes.
  The fixtures come from =POSLIB=, a poslib checkout, else from =poslib/=,
  cloned and brought to =POSLIB_REF=, default =master=.
- =make check-ipfs IPFS=path/to/ipfs=: the CID fixtures against kubo,
  offline, with the unixfs-v1-2025 profile.
